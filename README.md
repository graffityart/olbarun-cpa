# 올바른광고 (Olbarun CPA)

CPA 광고와 포스팅 광고를 하나의 파트너·광고주·정산 시스템에서 운영하는 성과형 광고 플랫폼입니다.

## 1차 개발 범위

- 공개 홈페이지
- 파트너 회원/대시보드
- 광고주 관리
- 관리자센터
- CPA 캠페인
- 자체 랜딩페이지 빌더
- 추적링크 / 클릭 / 전환 DB
- 중복 및 기본 어뷰징 탐지
- 승인·거절·이의제기
- 광고주 예치금 장부
- 파트너 수익 및 정산
- 포스팅 캠페인 / 작업 제출 / 수정요청 / 승인

## 기본 기술 스택

- Next.js + TypeScript
- PostgreSQL
- Drizzle ORM (초기 권장)
- Vercel 배포
- Object Storage (광고소재·계약서·증빙)

## 주요 영역

- `/` 공개 사이트
- `/partner` 파트너센터
- `/advertiser` 광고주센터
- `/admin` 관리자센터
- `/c/[code]` 파트너 추적링크
- `/l/[slug]` CPA 랜딩페이지

## 개발 원칙

1. CPA와 포스팅 광고는 계정·광고주·예치금·수익·정산을 공유합니다.
2. 전환 승인과 금액 처리는 하나의 DB 트랜잭션으로 실행합니다.
3. 승인취소·수익조정·광고비 환불은 기존 장부를 수정하지 않고 반대 거래를 추가합니다.
4. 고객 개인정보와 전환/추적 데이터는 논리적으로 분리합니다.
5. 개인정보 다운로드, 계좌 조회, 승인/거절, 단가/정산 변경은 감사로그를 남깁니다.
6. MVP는 CPA + 포스팅 광고에 집중하고 CPC/CPI/CPS 등은 제외합니다.

## 개발 단계

### Phase 1 — Foundation
프로젝트 골격, 공통 레이아웃, 인증/권한, DB 연결

### Phase 2 — Core entities
파트너, 광고주, 캠페인, 광고소재

### Phase 3 — CPA engine
랜딩페이지, 추적링크, 클릭, 전환, 중복/어뷰징, 승인/거절

### Phase 4 — Money
광고주 예치금, 파트너 수익, 정산, 감사로그

### Phase 5 — Posting
포스팅 캠페인, 참여, 작업결과 제출, 수정요청, 검수, 게시 유지

### Phase 6 — Reporting & launch
통계, Excel, 알림, 보안 점검, 백업, 실서비스 테스트
